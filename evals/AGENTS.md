# 模型评测指南

## 范围

- 本目录只存放必须显式运行的真实模型评测代码和固定数据，不存模型输出、运行日志、API Key 或真实面试录音。
- 普通单元测试不得放在这里；测试应位于源码旁的 `*.test.ts` 或根目录 `tests/`，并通过依赖注入避免访问真实模型。
- 评测必须调用独立 LLM 裁判，按配置阈值设置退出码；不得用字符串包含、固定文件名或同一个被测模型自评代替语义裁判。

## 案例规范

- 问题改写覆盖依赖上下文、明确切换项目和独立问题；检索评测覆盖多意图、语义改写和错误候选挤占 Top 2。
- 预期描述判断语义，不要求模型逐字匹配某一种英文改写。
- 新增影响模型行为的规则时，先补充能失败的代表案例，再调整 prompt 或实现。
- 案例不得包含真实候选人隐私、公司机密或模型服务配置。
