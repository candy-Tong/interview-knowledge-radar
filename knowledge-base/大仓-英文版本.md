我是大仓的负责人，推动 8+ 个项目迁移到 Monorepo。目前大仓承载 23 个项目和 22 个公共包。<br>
As the frontend monorepo owner, I promote more than eight projects move into the monorepo. It now contains 23 projects, and 22 shared packages.

在这个项目中，我主要做了以下几件事：<br>
In this project, I mainly did the following things:

Monorepo 统一了目录结构、依赖、构建配置和代码规范，让项目复用同一套基建，也为 AI 编码提供了统一的工程上下文。<br>
The monorepo gives all projects the same structure, dependencies, build settings, and coding rules. This helps them share the same project context for AI coding.

统一请求库集中管理并复用远端 API 代码，减少了重复下载和重复开发，使流水线构建时间缩短 50 秒。<br>
The shared request utils can reuses remote API code in one place. It reduces repeated downloads and development work, and cuts 50 seconds from the pipeline build time.

统一流水线通过缓存和构建优化，将构建时间从 5 分钟降到 2 分钟内。ESLint、TypeScript 检查等质量门禁也能自动检查 AI 生成的代码。<br>
The shared pipeline uses caching and build improvements to reduce build time from five minutes to under two minutes. Quality checks such as ESLint and TypeScript also check AI-generated code automatically.

将项目从部门老框架迁移到公司级框架，页面 LCP 降低约 30%，构建时间缩短 2 分钟，产物大小减少 21%。<br>
We moved the projects from the department's old framework to the company-level framework. This reduced page LCP by about 30%, cut build time about two minutes, and reduced output size by 21%.

Arco ProTable 和 Formily 统一了 CRUD 页面的开发方式。在 AI 辅助下，一个 CRUD 页面可以在 10 分钟内完成；<br>
Arco ProTable and Formily give us one standard way to build CRUD pages. With AI support, a CRUD page can be completed in under ten minutes.
