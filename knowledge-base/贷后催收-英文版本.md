我是贷后催收平台的核心开发，这个平台服务 11,000+ 名催员。催员使用这个系统联系和跟进逾期用户，系统同时提供管理、质检、审批、监控、配置、报表和考培等能力。<br>
I am a core developer of the post-loan collection platform, which serves more than 11,000 collection agents. They use the platform to contact and follow up with users who have overdue payments. It also provides management, quality checks, approvals, monitoring, configuration, reporting, and training.

我在项目中重点建设了全栈 AI 研发体系。通过沉淀项目上下文和历史经验，让 Agent 能够根据技术设计完成前后端开发、代码检查和页面验证。我们将 ESLint、TypeScript 检查、CodeReview 和浏览器验证接入执行链路，形成自动检查、修复和复验的闭环；基于真实需求建立评测集，用例通过率达到 92%。<br>
A major part of my work was building a full-stack AI development workflow. We gave the Agent project context and knowledge from earlier work, so it could work from a technical design and complete both frontend and backend development, code checks, and page verification. We connected ESLint, TypeScript checks, code review, and browser testing into one workflow, creating a loop of checking, fixing, and testing again. On a test set built from real tasks, 92% of the cases passed.

其他方面，我还参与了性能、稳定性、电话条和技术债治理。我们把 LCP 2 秒内打开率从 20%+ 提升到 80%+，将 4,000+ 个坐席迁移到免安装、免密码的网络电话，每月节省约 700 小时运维成本；同时对电话条进行了插件化改造，降低后续业务接入成本。<br>
In other areas, I also worked on performance, stability, the call tool, and technical debt. We improved page LCP two seconds open rate from over 20% to over 80%. We also moved more than 4,000 seats to web calls with no app or password needed, saving about 700 hours of operational work each month. We made the call tool plug-in based, so it is easier to support new business needs.
