# KnowledgeRadar 开发指南

## 职责

本组件展示当前 `InterviewQuestion` 绑定的知识结果。固定渲染两个槽位：有结果时显示完整知识，无结果时显示检索/等待状态。

## 关键约束

- 最多展示两条结果，与服务端 `maximumKnowledgeResults` 一致。
- 不显示重复的 QUERY 标题区；当前问题已经由左栏承载。
- 正文完整展示在各自滚动区，不按段落生成额外卡片。
- 使用 `focusStart`/`focusEnd` 对原始 content 做 `slice()` 并标记相关句；先夹紧边界，防止异常偏移破坏渲染。
- 没有可靠焦点时插入文首 fallback anchor。
- 切换 segment 或焦点变化时，两个滚动区分别平滑滚动到自己的 anchor；优先让高亮区域中心与正文容器中心对齐，靠近顶部或底部时夹紧到可滚动边界。
- 相关性数字不是概率，不添加百分号或“置信度”文案。

## 实现注意

- 自动滚动使用组件根 ref 限定查询范围，避免影响总览或其他滚动区。
- effect 依赖稳定的结果身份和 questionId，防止普通重渲染反复把用户拉回焦点。
- 高亮必须保持可读的马卡龙浅色，并继承正文颜色与字号。

## 验证

覆盖两条结果、一条结果、无结果、检索错误、焦点在长文中后部、无焦点以及点击历史问题后重新定位。
